서버 실행(server.py) 없이도 GitHub Pages 링크만으로 전 세계 어디서나 4명의 풀이를 100% 영구 자동 저장하고 실시간으로 공유할 수 있습니다.

1
Firebase 콘솔 (링크)에 구글 로그인 후 [프로젝트 만들기]를 누릅니다 (프로젝트명: 자유롭게).
2
왼쪽 메뉴의 [빌드] → [Realtime Database]를 클릭하고 [데이터베이스 만들기]를 누릅니다 (보안 규칙: 테스트 모드에서 시작 선택).
3
데이터베이스 상단에 표시되는 URL (예: https://프로젝트명-default-rtdb.firebaseio.com)을 복사하여 아래에 붙여넣고 [연결 저장]을 누르면 즉시 동기화됩니다!
💡 URL 입력 후 [연결 & 즉시 동기화]를 누르면 다른 컴퓨터/브라우저에서도 이 URL을 통해 완전히 동기화됩니다.
